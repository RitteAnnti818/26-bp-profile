## 소개

저는 JBNU에서 컴퓨터공학과 인공지능을 공부하는 학부생 **Heeyeon Kim**입니다. 현재 Machine Intelligence Lab에서 연구 경험을 쌓고 있으며, 3D Vision과 Computer Graphics에 관심이 있습니다.

## 관심 분야와 이유

단안 깊이 추정 기반 비정형 장애물 탐지를 다룬 경험을 통해, 한 장의 2D 영상에서 장면의 3D 구조를 추론하는 문제에 관심을 넓혔습니다. 눈에 보이는 픽셀을 공간의 거리와 형태로 연결하는 과정이 자율주행·로봇 인지뿐 아니라 사실적인 그래픽 표현에도 이어진다는 점이 흥미롭습니다.

## 기술과 적용 사례

- **Hugo**: 이 포트폴리오의 콘텐츠와 페이지를 정적 HTML로 생성했습니다.
- **Git/GitHub**: 기능 단위 커밋으로 변경 이력을 남기고 GitHub Actions 배포 흐름을 구성했습니다.
- **Python**: 수업 제공 스크립트로 테마와 GitHub Pages 설정을 점검했습니다.
- **Computer Vision**: 단안 깊이 추정 기반 비정형 장애물 탐지 주제를 연구·발표했습니다.
