# Manual QA: keyboard access

Reload the public home page and do not use the mouse. Press Tab to reveal the skip link and activate it with Enter. Continue through the home link, menu, theme toggle, hero actions, quick links, activities, social links, credit, and back-to-top control.

Require a visible focus indicator at every step, correct Enter activation, no keyboard trap, and a working path back to the top or home. Repeat the sequence with the mobile navigation layout. If focus order or naming is unclear, record the exact control and viewport before changing code.
