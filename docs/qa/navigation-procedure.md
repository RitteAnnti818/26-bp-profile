# Manual QA: navigation and history

Open the deployed home page in a signed-out window. Click each main menu item, the two hero actions, the three quick-navigation cards, both activity entries, GitHub, email, theme credit, home icon, and back-to-top control.

For About and the representative project, paste the URL into a new tab, refresh it, navigate elsewhere, and use the browser Back button. Every label must match its destination, and no interaction may lead to an empty hash or demo URL.
