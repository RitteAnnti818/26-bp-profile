# P41–P50: accessibility and usability

- A keyboard-first skip link moves focus to `#main-content`.
- Menus and calls to action are native links; the mobile trigger has an associated label.
- `:focus-visible` uses a three-pixel amber outline with offset.
- No modal or focus-trapping widget is used.
- The avatar receives the author name; the workflow diagram has descriptive alt text.
- Theme icon links include titles and SVG titles; the navigation landmark has an accessible name.
- Page content uses one main heading followed by semantic section headings.
- The generated document locale is `ko-KR`, matching the Korean content.
- Links have underlines or component borders in addition to color.
- Reduced-motion preferences shorten transitions and animations.

Final confirmation requires one continuous Tab sequence on the deployed site.
