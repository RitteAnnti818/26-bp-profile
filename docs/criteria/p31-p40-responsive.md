# P31–P40: responsive layout

Required viewport sequence: 1440 × 900, 390 × 844, 768 × 900, then resize from 1440 to 390 and back without refreshing.

Inspect the header, hero text, buttons, card grid, activity list, long publication title, workflow image, footer, and table of contents. The custom card grid changes from three columns to one at 768px. Buttons use a minimum 44px height and stack at mobile width. Images keep intrinsic aspect ratio with `height: auto`.

At 200% desktop zoom, repeat the menu and representative activity navigation. Vertical growth is acceptable; horizontal clipping, hidden controls, and overlapping fixed elements are not.
